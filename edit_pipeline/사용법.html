1무엇을 해 주나

촬영본 폴더째 넣기→카메라·마이크 자동 정리→소리로 싱크→전사·화자 판정→컷 선별→앵글 배치→XML·자막·대본
  • 정리하지 않아도 됩니다. 카드 폴더(DCIM, PRIVATE 등), 무선 마이크 파일, 녹음기 파일을 그대로 넣으면 어떤 파일이 어느 카메라인지, 어느 게 녹음인지 알아서 가립니다.
  • 무엇이든 소리로 싱크합니다. 연수·세미지·여행 촬영 모두 됩니다. 녹음이 1.wav·2.wav 로 쪼개져도 이어 붙입니다.
  • 셀렉츠처럼 컷마다 모든 카메라를 쌓아 두고 한 대만 켠 멀티캠 XML, 화자별 자막, 화자·시각이 붙은 대본을 만듭니다.
  • 결과는 완성본이 아니라 1차 컷(러프컷)입니다. 마무리는 프리미어에서 합니다.

2폴더 구성

zip 파일을 F:\클로드자료 에 풀면 아래처럼 됩니다(다른 위치에 풀어도 똑같이 동작합니다).

F:\클로드자료\영상자동컷편집\ ├─ 설치.bat ← 처음 한 번 더블클릭 ├─ 실행.bat ← 편집할 때마다 더블클릭 ├─ 스타일학습.bat ← 셀렉츠/프리미어 XML 을 끌어다 놓기 ├─ 프리미어패널설치.bat ← 프리미어에 '영상 자동 컷편집' 패널 설치(처음 한 번) ├─ premiere_panel\ ← 패널 파일(설치.bat 이 프리미어로 복사) ├─ 사용법.html / 사용법.pdf ├─ input\ ← 여기에 프로젝트 폴더를 만들고 촬영본을 통째로 │ └─ 강릉여행\ (카드 폴더, 마이크 파일 그대로) ├─ script\ ← 연수 대본(.txt), 있을 때만 ├─ output\ ← 결과물(프로젝트별 폴더) ├─ work\ ← 중간 결과(싱크·전사). 지우면 처음부터 다시 계산 ├─ config\ ← 규칙(presets.json), 학습한 스타일(styles\) └─ 예시\ ← 연습용 예시 두 개(팟캐스트, 강릉)

3처음 한 번: 설치

윈도우

  1. python.org 에서 Python 3.12 를 받아 설치합니다. 설치 첫 화면 아래 “Add python.exe to PATH” 를 꼭 체크하세요.
  2. 영상자동컷편집 폴더의 설치.bat 을 더블클릭합니다. 필요한 것을 알아서 받습니다(5~10분).
  3. “설치 완료!” 가 나오면 끝입니다.
  4. 프리미어패널설치.bat 을 더블클릭하고 프리미어 프로를 다시 켭니다. 메뉴 창 → 확장 → 영상 자동 컷편집 에 패널이 생깁니다(프리미어 프로젝트를 자동으로 만들어 주는 패널).
파란 “Windows의 PC 보호” 창이 뜨면 추가 정보 → 실행을 누르세요. 직접 만든 배치 파일이라 뜨는 안내입니다.

맥

  1. python.org 에서 Python 3.12 설치
  2. 설치_맥.command 더블클릭(처음엔 우클릭 → 열기)
NVIDIA 그래픽카드가 있으면 전사가 빨라집니다. 없어도 동작합니다(CPU 사용, 더 오래 걸림). 첫 전사 때 음성 인식 모델(약 3GB)을 한 번 내려받습니다.

4매번 쓰는 법

  1. 촬영본 넣기 — input 안에 프로젝트 이름으로 폴더를 하나 만들고(예: 강릉여행), 카드와 녹음기 파일을 정리하지 말고 통째로 복사합니다.
  2. (연수라면) 대본 넣기 — 최종 대본을 script\강릉여행.txt 처럼 텍스트로 저장합니다. 쓰는 법은 아래 대본 작성법.
  3. 실행.bat 더블클릭 — 번호로 고릅니다.
    묻는 것답
    어떤 프로젝트?번호

5결과물 (output\프로젝트\)

파일내용
프로젝트.prproj프리미어 프로젝트. 프리미어 패널이 만듭니다(아래 6번). 러프컷·싱크 타임라인·검토용 시퀀스와 화자별 캡션 트랙이 들어 있습니다
_러프컷.xml1차 컷 시퀀스. 셀렉츠처럼 컷마다 모든 카메라가 트랙별로 쌓여 있고 한 대만 켜져 있습니다. 개인 마이크 켜짐, 카메라 소리는 꺼진 채 포함, 주제 마커
_싱크타임라인.xml촬영 전체를 녹음 시간축에 펼친 멀티캠(셀렉츠 ‘싱크 타임라인’). 싱크가 안 된 인서트 영상은 맨 뒤에
_검토용.xml모든 테이크를 원래 순서대로. 뺀 테이크는 꺼진 클립 + 이유 마커
_자막.srt대사 자막(러프컷 기준)
_자막_화자표시.srt줄마다 [이형] 처럼 화자 표시
_자막_화자별\화자마다 SRT 하나(강릉여행_이형.srt …)
_대본.txt러프컷 대본: 주제 제목 아래 [00:03:12] 이형 문장
_전체전사.txt촬영 전체 전사. 러프컷에서 뺀 부분은 ✂(이유)
_포인트자막.srt대본의 **강조** 문구(연수)
_챕터.txt유튜브 설명란용 타임스탬프
_타임라인.html결과를 눈으로 확인하는 뷰어(크롬·엣지)
_리포트.md카메라 판정 근거, 마이크 오프셋, 싱크 신뢰도, 뺀 테이크 목록 등
_프리미어.json프리미어 패널이 읽는 작업 목록(건드리지 않아도 됩니다)

6프리미어에서 열기

결과는 XML(어디서나 열리는 교환 형식)과 프리미어 프로젝트(.prproj) 두 가지로 받을 수 있습니다. .prproj 는 프리미어가 직접 만들기 때문에 프리미어 버전이 바뀌어도 문제없이 열립니다.

방법 1 — 패널이 .prproj 를 만들어 줌(추천)

  1. 프리미어 프로에서 창 → 확장 → 영상 자동 컷편집 패널을 엽니다(처음 한 번 프리미어패널설치.bat 필요).
  2. 결과 목록에서 프로젝트 만들기를 누릅니다. 몇 초 뒤 output\프로젝트\프로젝트.prproj 가 만들어지고 열립니다.
    • 러프컷 시퀀스(카메라가 쌓인 멀티캠, 한 대만 켜짐)
    • 싱크 타임라인·검토용 시퀀스
    • 화자별 캡션 트랙(이형, 시온 … 사람마다 한 트랙)과 ‘자막’ 빈
  3. “새 결과 자동으로 프로젝트 만들기”를 켜 두면, 실행.bat 이 끝날 때마다 프리미어가 알아서 .prproj 를 만듭니다(프리미어를 켜 둔 상태에서).
패널 위쪽 경로는 설치할 때 자동으로 채워집니다. 폴더를 옮겼으면 찾기로 영상자동컷편집 폴더를 다시 지정하세요. 결과를 다시 만들면 상태가 “결과가 새로 바뀜” 으로 바뀌고, 다시 만들기로 갱신할 수 있습니다.

방법 2 — XML 을 직접 가져오기

  1. 프리미어에서 새 프로젝트를 만들고 파일 → 가져오기(Ctrl+I) → _러프컷.xml(또는 _싱크타임라인.xml). 프로젝트 창으로 끌어다 놓아도 됩니다.
  2. Ctrl+S 로 저장하면 .prproj 가 됩니다.
  3. 자막: 파일 → 가져오기 → SRT → 타임라인으로 끌어다 놓기. 화자별 SRT 를 각각 올리면 화자마다 트랙이 됩니다.

공통

  • “미디어 오프라인” 이 뜨면 원본 폴더를 옮겼기 때문입니다. 미디어 연결로 원본 폴더를 지정하세요.
  • 앵글 바꾸기: 같은 자리에 쌓인 다른 카메라 클립을 선택하고 Shift+E(사용) 로 켜고, 원래 켜져 있던 클립은 같은 키로 끕니다.
파이널컷 프로 X 는 이 XML(FCP7 형식)을 바로 열지 못합니다. 프리미어·다빈치 리졸브는 바로 열립니다. 반대로 .fcpxml(파이널컷 X 형식)은 프리미어가 못 엽니다 — 이 프로그램은 .fcpxml 을 학습·비교용으로 읽기만 합니다.

7화자별 자막

  • 무선 마이크가 여러 개면 단어마다 가장 크게 들어온 마이크를 화자로 봅니다.
  • 화자가 바뀌면 자막도 끊어서, 한 줄에 두 사람 말이 섞이지 않습니다.
  • 화자 이름은 마이크 파일 이름에서 가져옵니다(MIC이형1.wav → 이형, TX01_… → TX01). 사람 이름으로 바꾸려면 실행할 때 TX01=이형,TX02=시온 처럼 입력하세요.
  • 대본 대조 모드(연수)는 한 문장을 한 사람으로 봅니다.

8타임라인 뷰어 (_타임라인.html)

  • 러프컷 탭: 컷마다 쓴 카메라와 이유, 자막, 주제 마커
  • 원본 배열 탭: 녹음 기준으로 카메라별 파일 배치, 마이크별 파형, 테이크(초록 = 씀, 빨강 = 뺌)
  • 전사 패널: 화자 배지 + 문장. 누르면 그 자리로 이동
  • 카메라 패널: 카메라마다 역할과 판정 근거
  • 재생 Space, 이동 ←→(Shift 누르면 5초)
  • 테이크 고치기: 원본 배열에서 테이크를 두 번 누르면 씀/뺌이 바뀝니다 → 수정 저장(JSON) → 명령어 --overrides 저장한파일.json 로 다시 실행하면 XML·자막에 반영됩니다.
영상이 안 나오면 원본이 MXF·HEVC·4K 처럼 브라우저가 못 여는 형식이라서입니다. 명령어에 --proxy 를 붙여 다시 실행하면 저화질 미리보기 파일을 만들어 씁니다.

9셀렉츠 편집으로 스타일 학습

셀렉츠(또는 프리미어·파이널컷)에서 편집한 결과를 내보내 학습시키면, 다음부터 같은 스타일로 자릅니다.

  1. 셀렉츠에서 내보내기 → 어도비 프리미어(.xml) 또는 파이널컷(.fcpxml)
  2. 그 파일을 스타일학습.bat 아이콘 위로 끌어다 놓기
  3. 다음 실행 때 “편집 스타일” 에서 고르기

학습하는 것: 카메라별 사용 비율과 샷 길이(→ 정면·측면·컷어웨이), 한 앵글 최대 유지 시간, 화자가 바뀔 때 앵글 전환 여부, 카메라 쌓기·오디오 켜고 끄기, 시퀀스 설정(23.976fps 4K 등).

이미 들어 있는 스타일: 셀렉츠_팟캐스트25분(카메라 3대·개인 마이크 4개 팟캐스트 편집), 셀렉츠_강릉교육여행(카메라 5대 여행 촬영 편집) — 받은 zip 에만 들어 있습니다.

“누가 말할 때 어느 카메라” 까지 배우려면 마이크 원본이 있는 PC 에서, 명령어로 원본 폴더를 알려 주세요:
.venv\Scripts\python -m autocut learn 편집.xml --media "N:\원본폴더" --name 팟캐스트

10셀렉츠 싱크와 비교

같은 촬영을 셀렉츠로도 맞춰 둔 경우, 셀렉츠 결과를 정답으로 삼아 이 프로그램의 싱크가 맞는지 파일별로 확인합니다.

.venv\Scripts\python -m autocut run input\강릉여행 --until sync
.venv\Scripts\python -m autocut compare-sync 강릉_셀렉츠.fcpxml input\강릉여행

파일마다 오차(ms·프레임)를 보여 주고, 1프레임 넘게 어긋나면 ← 확인 표시를 합니다.

11옵션 모음(명령어)

영상자동컷편집 폴더에서 주소창에 cmd 를 입력해 명령 창을 열고 씁니다. 앞부분은 항상 .venv\Scripts\python -m autocut run input\프로젝트 입니다.

옵션쓰임
--script script\대본.txt대본 대조(연수)
--target 20m / shorts목표 길이로 줄이기(중요한 주제 우선)
--speakers "TX01=이형,TX02=시온"화자 이름
--roles "카드3=tele,C400=front"카메라 역할 직접 지정(front 정면 / side 측면 / tele 망원 / wide 와이드 / two 2인)
--style 셀렉츠_팟캐스트25분학습한 편집 스타일
--until sync싱크·카메라 판정까지만
--redo sync,transcribe싱크·전사를 처음부터 다시
--overrides 수정.json뷰어에서 고친 테이크 반영
--proxy뷰어용 저화질 미리보기 파일 만들기
--preset 연수촬영 유형 직접 지정(보통은 자동: 대본 있음→연수, 2인 구도→세미지, 녹음 여러 번→교과서여행)
카드 폴더 이름에 정면, 측면, 망원, 와이드 를 넣어 두면(예: A캠_정면) 카메라 역할 판정이 가장 확실합니다.

증상해결
설치.bat 에서 “파이썬이 없습니다”Python 3.12 설치 때 “Add python.exe to PATH” 체크 → 설치.bat 다시
전사가 너무 오래 걸림config\presets.json 의 "whisper_model": "large-v3" 를 "large-v3-turbo" 나 "medium" 으로(빠르지만 조금 덜 정확)
어떤 파일이 “인서트” 로 빠짐녹음과 소리가 안 맞는 영상(따로 찍은 풍경 등). 싱크 타임라인 맨 뒤에 모여 있습니다
카메라 역할이 틀림리포트의 카메라 표를 보고 --roles 로 지정
화자가 틀림마이크끼리 소리가 많이 섞이면 생깁니다. 뷰어 전사 패널로 확인

뷰어에서 영상이 검은 화면--proxy 로 다시 실행
