셀렉츠처럼 만들기 위한 자료 준비 목록

영상 자동 컷편집을 셀렉츠와 거의 같게 맞추려면 무엇을 보내면 되는지, 어떻게 만들고 어디에 쓰는지

핵심은 “같은 촬영의 원본 + 셀렉츠 결과” 한 쌍입니다. 정답(셀렉츠 결과)이 있어야 이 프로그램의 결과가 얼마나 다른지 숫자로 재고 고칠 수 있습니다. 원본은 전부가 아니어도 되고, 소리만으로도 대부분 됩니다.

1가장 먼저: 추천 한 세트

강릉 촬영에서 한 장소(예: 경포호·경포대) 분량으로 시작하는 것을 권합니다. 셀렉츠 결과(.fcpxml)는 이미 받았으니 원본만 있으면 바로 맞대어 볼 수 있습니다.

  1. 원본 폴더를 가볍게 만들기 — 그 장소의 카드 폴더와 마이크 파일이 든 폴더를 자료보내기용_가볍게.bat 아이콘 위로 끌어다 놓습니다. “몇 분만?” 에는 엔터(전체). 영상은 180p 저화질, 마이크는 무손실 FLAC 으로 줄어 보낼자료 폴더에 모입니다(파일 이름·폴더 구조 그대로).
  2. 셀렉츠 전사 자막 내보내기 — 셀렉츠에서 같은 촬영을 열고 내보내기 → 자막(화자 표시가 있으면 켜기).
  3. (가능하면) 셀렉츠 싱크 결과 — 이미 보낸 강릉 .fcpxml 이면 생략. 다른 촬영이면 내보내기 → 파이널컷.
  4. 보내기 — 보낼자료 폴더를 zip 으로 묶어 대화창에 첨부하거나, 구글 드라이브에 올리고 알려 주세요(연결된 드라이브에서 바로 읽을 수 있습니다).

3용량 줄이는 법 (자료보내기용_가볍게.bat)

  • 촬영본 폴더를 아이콘 위로 끌어다 놓으면 영상자동컷편집\보낼자료\폴더이름 에 작은 사본이 생깁니다. 4K 원본이면 보통 수십 분의 1 크기가 됩니다.
  • 싱크·전사·화자 판정은 소리만 있으면 되므로 화질은 낮춰도 결과가 같습니다(시험 결과 원본 대비 오차 1.2ms 이내).
  • 파일 이름과 폴더 구조가 그대로라 셀렉츠 결과와 짝지어 비교됩니다.
  • “몇 분만?” 에 숫자를 넣으면 각 파일의 앞부분만 담습니다. 다만 녹음이 1.wav·2.wav 로 쪼개진 촬영은 전체(엔터)로 해 주세요. 앞부분만 자르면 두 녹음을 잇는 카메라 구간이 빠질 수 있습니다.
  • 명령어로는: .venv\Scripts\python -m autocut pack input\강릉 --minutes 20

4받은 뒤 제가 하는 것

자료하는 일 → 고치는 것
원본 + 셀렉츠 싱크 결과compare-sync 로 파일별 오차 표 → 1프레임 넘게 어긋난 파일의 원인(잡음, 시계 오차, 분할 녹화 등)을 찾아 싱크 규칙 수정
셀렉츠 전사·자막문장·시각·화자를 한 줄씩 비교 → 전사 설정(모델·잡음 처리), 화자 판정 기준(마이크 음량 차이) 조정
편집본 XML + 마이크 원본learn --media 로 화자 → 카메라, 샷 길이, 앵글 전환 규칙 학습 → 스타일 파일로 저장
주제별 정리 XML주제 경계와 제목 붙이는 방식 분석 → 주제 나누기·챕터 기능 개선
화면 캡처·요청 문장채팅 요청 처리, 검색, 클립 분석 등 셀렉츠 기능을 하나씩 구현

5주의할 점

  • 셀렉츠 프로그램 파일 자체는 필요 없습니다. 프로그램을 뜯어보는 방식은 라이선스 문제가 있어 쓰지 않습니다. 결과물과 화면만으로 충분합니다.
  • 자료에는 출연자 이름·얼굴·목소리가 들어갑니다. 받은 자료와 거기서 학습한 스타일은 공개 저장소에 올리지 않고 선생님께 드리는 파일에만 반영합니다. 보내기 전에 출연자 동의 범위(제작 목적 외 사용)를 한 번 확인해 주세요.
