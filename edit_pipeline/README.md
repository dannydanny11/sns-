# 영상 자동 컷편집 파이프라인

촬영본 폴더를 넣으면 **싱크 → 전사 → 컷 선별 → 앵글 배치 → 프리미어 XML** 까지 자동 처리한다.
출력은 완성본이 아니라 1차 컷(러프컷)이고, 최종 편집은 프리미어에서 사람이 마무리한다.
설계 문서: "영상 자동 컷편집 파이프라인 설계 초안 v2".

## 설치 (로컬 PC)

```bash
cd edit_pipeline
pip install -r requirements.txt
```

- ffmpeg 가 PATH 에 있으면 그걸 쓰고, 없으면 `imageio-ffmpeg` 에 들어 있는 실행 파일을 쓴다. 직접 지정하려면 `FFMPEG=/경로/ffmpeg`.
- 전사는 faster-whisper `large-v3` (첫 실행 시 모델 다운로드 약 3GB). GPU 가 있으면 자동으로 사용한다.

## 폴더 구조

```
edit_pipeline/
├─ input/<프로젝트>/
│  ├─ cam_front/  cam_side/  cam_tele/  cam_wide/  cam_two/ …   (단일 폴더형)
│  ├─ <장소>/cam_front/ …                                      (장소별 폴더형, 교과서 여행)
│  └─ audio/                                                     별도 녹음기 파일
├─ script/        최종 대본(연수용, 있을 때만)
├─ work/          단계별 JSON (sync / transcript / plan / subtitle)
├─ output/        프리미어 XML, SRT, 챕터, 리포트
└─ config/presets.json   촬영 유형별 규칙
```

카메라 구분은 폴더명으로 한다(`cam_` 뒤의 이름이 역할: front, side, tele, wide, two). 파일명 규칙은 필요 없다.
장소 폴더 안에 `audio/` 가 있으면 그 장소는 그 녹음을 기준으로 삼는다.

## 실행

```bash
# 연수(대본 낭독): 대본 대조 모드
python -m autocut run input/연수_3차시 --preset 연수 --script script/연수_3차시.txt

# 세미지: 대본 없이, 20분으로 줄이기
python -m autocut run input/세미지_0924 --preset 세미지 --target 20m

# 교과서로 떠나는 여행: 쇼츠 구간만
python -m autocut run input/교과서여행_경주 --preset 교과서여행 --target shorts

# 싱크까지만 돌려서 오프셋 확인 → 이상 없으면 이어서 실행(싱크 결과 재사용)
python -m autocut run input/세미지_0924 --preset 세미지 --until sync

# 싱크·전사를 다시 하고 싶을 때
python -m autocut run input/세미지_0924 --preset 세미지 --redo sync,transcribe
```

싱크·전사 결과는 `work/` 에 남아 다음 실행에서 재사용한다. 컷 선별 이후는 매번 새로 계산하므로
`config/presets.json` 규칙만 바꿔 다시 돌리면 몇 초 안에 새 XML 이 나온다.

## 출력물 (`output/<프로젝트>/`)

| 파일 | 내용 |
| --- | --- |
| `_러프컷.xml` | 채택 테이크만 이어 붙인 시퀀스. V1 앵글 배치, A1/A2 별도 녹음, 챕터 마커 |
| `_검토용.xml` | 모든 테이크를 원래 순서로 늘어놓고 탈락 테이크는 꺼진(비활성) 클립으로 둔 시퀀스. 사유는 마커와 클립 코멘트 |
| `_자막.srt` | 대사 자막. 대본 모드는 대본 문장(맞춤법 정확), 자유 모드는 전사 텍스트 |
| `_포인트자막.srt` | 대본의 `**강조**` 문구가 실제 발화된 구간(앞뒤 여유·최소·최대 노출 적용) |
| `_챕터.txt` | 유튜브 설명란용 타임스탬프 |
| `_리포트.md` | 싱크 오프셋·신뢰도, 제외 카메라, 누락 파일, 탈락 테이크 목록, 대본 누락 문장, 앵글 분포 |

프리미어: 파일 → 가져오기 → XML 선택. 원본 경로가 바뀌었으면 미디어 재연결이 필요하다.
자막 SRT 는 캡션 트랙으로 가져와 기존 캡션 스타일 프리셋을 적용한다.

## 대본 작성법 (연수)

```
# 들어가며
안녕하세요 선생님 여러분. 오늘은 **수업 설계의 세 가지 원칙**을 살펴보겠습니다.

# 첫 번째 원칙
첫 번째는 학습 목표를 먼저 정하는 것입니다.
```

- `# 제목` 또는 빈 줄 → 주제 전환(챕터 마커 + 와이드 샷)
- `**문구**` → 포인트 자막 후보 + 망원 샷. 미리 표시해 두면 정확도가 크게 오른다.

## 단계별 동작

1. **싱크**: 카메라 오디오를 2kHz 로 내려 기준 녹음과 GCC-PHAT 상호상관 → 16kHz 30초 창으로 정밀 보정.
   신뢰도(최고 피크 대비 두 번째 피크)·z 점수가 기준 미달이면 그 파일은 제외하고 리포트에 남긴다.
   슬레이트(박수) 피크는 검증용으로만 본다. 녹음 파일이 없거나 손상되면 정면 카메라 오디오를 기준으로 쓴다.
2. **전사**: 기준 녹음 하나만 faster-whisper 로 전사(한국어 고정, 단어 타임스탬프). 대본이 있으면 앞부분을 용어 힌트로 넣는다.
3. **컷 선별**: 필러(어, 음…)·더듬음 제거, 쉼 구간 제거(앞뒤 여유 유지).
   대본 대조 모드는 구절을 대본 문장에 유사도로 정렬하고, 같은 문장이 다시 나오면 재촬영으로 보고
   마지막 완결 테이크만 채택한다. 문장 중간에 쉬었다 이어 말한 경우는 한 테이크로 합친다.
   `--target` 을 주면 주제 단위로 중요도를 매겨(ANTHROPIC_API_KEY 가 있으면 Claude Sonnet, 없으면 정보 밀도) 목표 길이에 맞춘다.
4. **앵글 배치**: 기본 정면, 주제 전환 첫 샷 와이드, 강조 대목 망원, 잘라낸 자리(점프컷)는 다른 앵글로 덮기,
   한 앵글이 오래 가면 측면으로 잠깐 전환, 최소 샷 길이 보장. 해당 시각을 찍지 않은 카메라·싱크 실패 카메라는 자동 제외.
5. **내보내기**: FCP7 XML(xmeml v4). 프리미어 구/신버전, 다빈치에서 열린다.

## 프리셋 조정 (`config/presets.json`)

`default` 위에 유형별 값을 덮어쓴다. 자주 만지는 값:

| 키 | 의미 |
| --- | --- |
| `roles` | 슬롯(base/wide/tele/alt)에 쓸 카메라 역할. 연수는 와이드·망원이 없어 측면으로 대체 |
| `max_hold` / `alt_hold` | 한 앵글 최대 유지 시간 / 측면 전환 길이 |
| `min_shot` | 최소 샷 길이(과도한 컷 방지) |
| `pad_before` / `pad_after` | 잘라낸 자리 앞뒤 여유 |
| `join_gap` | 이 시간보다 긴 쉼은 잘라낸다 |
| `keep_off_script` | 대본에 없는 발화를 살릴지(세미지·여행은 true) |
| `min_coverage` | 문장의 몇 % 이상 말해야 완결 테이크로 볼지 |

## 테스트

```bash
python -m pytest -q tests
```

합성 촬영본(카메라 3대 + 별도 녹음, 한 대는 무관한 소리)을 만들어 싱크 오프셋, 재촬영 판정,
XML 구조, 자막까지 확인한다. Whisper 는 가짜 전사로 대체한다.

## 아직 안 된 것 (설계 문서의 후순위 단계)

- 포인트 자막 `.mogrt` 템플릿 주입(현재는 SRT 와 `work/subtitle/*.json` 으로 문구·시간만 제공)
- 단어 단위 컬러 강조(프리미어 스크립팅 필요)
- 렌더 후 자동 검수, 플랫폼별 리사이즈, 미디어 인덱싱, 자막 번역
