# 영상 자동 컷편집 파이프라인

촬영본 폴더를 **통째로** 넣으면 알아서 정리 → 싱크 → 전사 → 컷 선별 → 앵글 배치 → 프리미어 XML 까지 만든다.
연수든 세미지든 여행 촬영이든 파일이 무엇이든 소리로 싱크를 맞춘다.
출력은 완성본이 아니라 1차 컷(러프컷)이고, 최종 편집은 프리미어에서 사람이 마무리한다.

---

## 설치

### Windows

1. https://www.python.org/downloads/ 에서 Python 3.12 설치 — **첫 화면 아래 "Add python.exe to PATH" 꼭 체크**
2. zip 을 `C:\autocut` 에 풀기 (→ `C:\autocut\edit_pipeline`)
3. PowerShell 에서:
   ```powershell
   cd C:\autocut\edit_pipeline
   py -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   ```
   `Activate.ps1` 에서 "스크립트를 실행할 수 없습니다" 가 나오면 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` 를 한 번 실행한 뒤 다시.
4. 다음부터는 PowerShell 을 열 때마다 `cd C:\autocut\edit_pipeline` → `.\.venv\Scripts\Activate.ps1`

NVIDIA 그래픽카드가 있으면 전사가 빨라진다: `pip install nvidia-cublas-cu12 nvidia-cudnn-cu12` (안 잡히면 CPU 로 동작).

### Mac

1. https://www.python.org/downloads/ 에서 Python 3.12 설치 (또는 `brew install python@3.12`)
2. zip 을 풀어 `edit_pipeline` 폴더를 `~/autocut/` 에 두기
3. 터미널에서:
   ```bash
   cd ~/autocut/edit_pipeline
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```
4. 다음부터는 `cd ~/autocut/edit_pipeline && source .venv/bin/activate`

Mac 에서는 Whisper 가 CPU 로 돈다(M 칩이면 쓸 만함). 뷰어는 사파리보다 크롬 권장.

### 설치 확인
```
python -m pytest -q tests
```

ffmpeg 는 따로 설치하지 않아도 된다(없으면 패키지에 들어 있는 것을 씀). 첫 전사 때 Whisper 모델(약 3GB)을 내려받는다.

## 쓰는 법

### 1) 촬영본을 통째로 넣는다

```
edit_pipeline/input/강릉여행/        ← 프로젝트 폴더 하나 만들고
   (카드 폴더, 무선 마이크 파일, 녹음기 파일을 정리하지 말고 그대로 복사)
```

카드 구조(`DCIM/100CANON`, `PRIVATE/M4ROOT/CLIP`, `CLIPS001` …)·파일 이름 규칙은 신경 쓰지 않아도 된다.
프록시·썸네일·사이드카(`.LRV .THM .XML`, `SUB/`, `._*`)는 알아서 건너뛴다.

### 2) 실행

```bash
python -m autocut run input/강릉여행                          # 전부 자동
python -m autocut run input/연수_3차시 --script script/연수_3차시.txt   # 대본이 있으면(연수)
python -m autocut run input/세미지_0924 --target 20m          # 20분으로 줄이기
python -m autocut run input/강릉여행 --target shorts          # 쇼츠 구간만
```

자주 쓰는 옵션

| 옵션 | 쓰임 |
| --- | --- |
| `--until sync` | 싱크·카메라 판정까지만 하고 멈춤(결과부터 확인할 때) |
| `--roles "카드3=tele,카드1=front"` | 카메라 역할 판정이 틀렸을 때 직접 지정(front 정면 / side 측면 / tele 망원 / wide 와이드 / two 2인) |
| `--preset 연수` | 촬영 유형을 직접 지정(생략하면 자동: 대본 있음→연수, 2인 구도→세미지, 녹음 여러 번→교과서여행) |
| `--proxy` | 뷰어 미리보기용 저화질 사본(원본이 MXF·HEVC·4K 라 브라우저가 못 열 때) |
| `--overrides <파일>` | 뷰어에서 고친 테이크 채택/탈락 반영 |
| `--redo sync,transcribe` | 싱크·전사를 처음부터 다시 |

싱크·전사 결과는 `work/` 에 남아 다음 실행에서 재사용된다. 옵션만 바꿔 다시 돌리면 몇 초면 끝난다.

### 3) 결과 (`output/<프로젝트>/`)

| 파일 | 내용 |
| --- | --- |
| `_싱크타임라인.xml` | 셀렉츠의 '싱크 타임라인'. 촬영 전체를 녹음 시간축에 펼친 멀티캠 시퀀스. 카메라마다 비디오 트랙, 마이크마다·카메라마다 오디오 트랙. 녹음 세션마다 마커, 싱크 안 된 인서트는 맨 뒤 |
| `_러프컷.xml` | 채택 테이크만 이어 붙인 1차 컷. V1 앵글 배치, 마이크 트랙 전부, 챕터 마커 |
| `_검토용.xml` | 모든 테이크를 원래 순서로, 탈락 테이크는 꺼진 클립으로 |
| `_타임라인.html` | 타임라인 뷰어(아래) |
| `_자막.srt` / `_포인트자막.srt` | 대사 자막 / 대본 `**강조**` 문구 |
| `_챕터.txt` | 유튜브 설명란용 타임스탬프 |
| `_리포트.md` | 카메라 판정 근거, 마이크 오프셋, 싱크 신뢰도, 인서트·무시한 파일, 탈락 테이크, 앵글 분포 |

프리미어: 파일 → 가져오기 → XML. 원본 경로가 바뀌었으면 미디어 재연결.

## 자동으로 알아내는 것

| 무엇 | 어떻게 |
| --- | --- |
| 기준 녹음 | 소리만 있는 파일(무선 마이크·녹음기) 중 가장 긴 것. 같은 순간을 녹음한 파일(TX01~TX04, Tr1/Tr2/LR)은 한 묶음으로 보고 **각각 오디오 트랙**으로 둔다. 녹음 파일이 없으면 가장 긴 카메라 소리 |
| 싱크 | 모든 영상 파일을 하나씩 녹음과 상호상관(GCC-PHAT → 16kHz 정밀 보정). 긴 파일은 여러 지점을 재서 **카메라·녹음기 시계 오차(드리프트)** 까지 보정 |
| 분할 녹화 | 말소리가 없어 싱크가 안 되는 파일도, 같은 카메라의 앞 파일에 촬영 시각이 이어지면 바로 뒤에 붙인다 |
| 인서트 | 녹음과 소리가 맞지 않는 영상(따로 찍은 풍경 등)은 러프컷에서 빼고 싱크 타임라인 맨 뒤에 모아 둔다 |
| 카메라 구분 | 카드 폴더, 기종·시리얼(메타데이터·소니 XML), 파일 이름 패턴, 해상도·fps 로 묶고, **시간이 겹치는 파일은 다른 카메라**로 나눈다 |
| 카메라 역할 | ① 폴더 이름(정면·측면·망원·와이드·2인·A캠·B캠 …) ② 얼굴 분석(정면 얼굴→정면, 옆얼굴→측면, 큰 얼굴→망원, 작은 얼굴→와이드, 두 명→2인) ③ 분량이 가장 긴 카메라를 정면 |
| 화자 | 무선 마이크가 여러 개면 단어마다 가장 크게 들어온 마이크를 화자로(뷰어 전사 패널에 표시) |
| 촬영 유형 | 대본 있음→연수, 2인 구도→세미지, 녹음 세션 여러 개→교과서여행 |

카드 폴더 이름에 `정면`, `측면`, `망원` 같은 말을 붙여 두면 역할 판정이 가장 확실하다(예: `A캠_정면`).

## 타임라인 뷰어 (`_타임라인.html`)

크롬·엣지로 연다(인터넷 불필요).

- **러프컷**: V1 샷(카메라별 색 + 배치 이유), 자막, 포인트 자막, 챕터 마커
- **원본 배열**: 녹음 기준으로 카메라별 클립 배치, 마이크별 파형, 테이크(초록 채택 / 빨강 탈락)
- **전사 패널**: 화자 배지 + 문장, 주제별 묶음, 탈락 이유. 누르면 그 지점으로 이동, 재생 중엔 현재 문장 강조
- **카메라 패널**: 카메라별 역할과 판정 근거, 인서트 수, 화자 목록
- **재생**: 스페이스바, ←/→ 1초(Shift 5초). 원본 배열에서는 카메라 이름을 눌러 모니터 전환
- **테이크 수정**: 원본 배열에서 테이크를 두 번 누르거나 [채택하기/탈락시키기] → [수정 저장(JSON)] → `--overrides` 로 재실행

## 대본 작성법 (연수)

```
# 들어가며
안녕하세요 선생님 여러분. 오늘은 **수업 설계의 세 가지 원칙**을 살펴보겠습니다.

# 첫 번째 원칙
첫 번째는 학습 목표를 먼저 정하는 것입니다.
```

- `# 제목` 또는 빈 줄 → 주제 전환(챕터 마커 + 와이드 샷)
- `**문구**` → 포인트 자막 + 망원 샷
- 같은 문장을 다시 읽으면 마지막(끝까지 읽은) 테이크만 채택, 앞 테이크는 비활성 클립으로 남김

## 규칙 조정 (`config/presets.json`)

`default` 위에 유형별 값을 덮어쓴다.

| 키 | 의미 |
| --- | --- |
| `roles` | 편집 슬롯(base 기본 / wide 주제 전환 / tele 강조 / alt 측면 전환)에 쓸 카메라 역할 |
| `max_hold` / `alt_hold` / `min_shot` | 한 앵글 최대 유지 / 측면 전환 길이 / 최소 샷 길이 |
| `pad_before` / `pad_after` / `join_gap` | 잘라낸 자리 앞뒤 여유 / 이보다 긴 쉼은 자름 |
| `keep_off_script` | 대본에 없는 발화를 살릴지 |
| `whisper_model` | `large-v3`(정확) → 느리면 `large-v3-turbo` 나 `medium` |
| `min_confidence` | 싱크 신뢰도 기준(낮추면 더 많이 붙지만 오판 위험) |

## 옛 방식(폴더 정리)도 그대로 됨

`input/<프로젝트>/cam_front/`, `cam_side/`, `audio/` 처럼 나눠 넣으면 폴더 이름을 그대로 카메라·역할로 쓴다.

## 아직 안 된 것

- 포인트 자막 `.mogrt` 템플릿 주입, 단어 단위 컬러 강조(프리미어 스크립팅 필요)
- 렌더 후 자동 검수, 플랫폼별 리사이즈, 미디어 인덱싱, 자막 번역
- 화자 이름 지정(현재는 마이크 이름 TX01 등으로 표시)
